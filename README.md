## 📖 Bối Cảnh Cốt Truyện (The Narrative)

**Đêm 24 tháng 10 năm 1989**, cơn mưa rào trái mùa xối xả trút xuống dòng kênh Bến Hàm Tử (Quận 5, Chợ Lớn). Đúng **20h30**, toàn bộ khu vực bến tàu bị cắt điện đột ngột. 

Trong bóng tối và tiếng sấm chớp rền vang, **Lương Vĩnh Phát (62 tuổi)** — ông chủ tiệm kim hoàn Vạn Lợi khét tiếng Chợ Lớn, trùm đường dây ký gửi vàng lá ngầm xuyên biên giới — bị sát hại dã man ngay tại thư phòng tầng 2. 

Cánh cửa gỗ lim dày 8cm cài then ngang bằng đồng chắc chắn từ bên trong. Nạn nhân gục chết trên bàn cờ Tướng ngà voi với vết siết hằn kép 0.8mm trên cổ họng, nhưng tách trà sen bên cạnh vẫn còn tỏa hơi ấm sau hơn 2 giờ cúp điện. 

Người chơi vào vai **Thám tử thuộc Cơ quan Cảnh sát Điều tra Hình sự #427**, bước vào ngôi nhà 3 tầng ven kênh để phá vỡ ảo tưởng phòng kín bất khả xâm phạm, lật tẩy các bằng chứng ngoại phạm giả tạo và vạch mặt hung thủ thực sự trước khi bình minh ló rạng.

## 🎮 Tính Năng Trọng Tâm (Core Game Systems)

### 1. Khám Nghiệm Hiện Trường 3D (Three.js Noir Viewport)
- **Ánh Sáng Đèn Pin Điều Tra Chân Thực:** Hệ thống chiếu sáng động theo con trỏ chuột mô phỏng đèn pin chuyên dụng soi rọi không gian tăm tối thời kỳ cúp điện 1989.
- **Hệ Thống Thẻ Đánh Số Tang Vật (Evidence Tent Markers):** Tự động cắm biển số hiện trường (#01 đến #14) khi người chơi phát hiện manh mối vật lý.
- **Giám Định Hiện Vật 3D 360°:** Tương tác xoay trục, tháo lắp cơ khí các vật phẩm then chốt:
  - *Quân Hắc Tướng Ngà Voi cưa đôi* giấu vi phim tài liệu chuyển vàng lậu 1984.
  - *Ấm trà sen hai đáy* tỏa nhiệt bằng phản ứng hóa học tôi vôi sống ($CaO + H_2O \rightarrow Ca(OH)_2$).
  - *Cơ chế then cài cửa gỗ lim* phòng kín.

### 2. Chuỗi Minigame Pháp Y & Cơ Khí (Pixi.js & Phaser 3)
- **Kính Hiển Vi Quang Học Leitz Wetzlar 10x (Pixi.js):** So sánh vết xước vi thể và đường kính 0.8mm giữa rãnh siết cổ tử thi với dây số 2 của cây đàn Tỳ bà treo trên vách.
- **Thực Nghiệm Cơ Học Phòng Kín (Pixi.js Physics):** Tái hiện thao tác dùng sợi chỉ tơ tằm sáp vàng luồn qua khe sàn gỗ 5mm để giật chốt then cài từ bên ngoài hành lang.
- **Ổ Khóa Đồng Cơ Khí Bát Quái (Pixi.js):** Xoay 3 vòng đồng tâm theo quẻ Dịch kinh cổ (*Càn - Khảm - Chấn*) để mở hộc bàn xưởng bạc.
- **Sơ Đồ Mặt Cắt Kiến Trúc 3 Tầng (Phaser 3 Blueprint):** Phân tích luồng di chuyển và độ cao giữa Bến Tàu (±0.00m), Xưởng Phân Kim (+3.40m) và Thư Phòng Án Mạng (+6.80m).
- **Ma Trận Thời Gian Đối Chiếu Ngoại Phạm (Golden Idol Deduction Grid):** Ghép nối thời gian, vị trí, âm thanh và hành động lúc 21h45 để lật tẩy băng ghi âm giả tạo.

### 3. Đấu Trí Thẩm Vấn & Đo Áp Lực Tâm Lý (Inkle Ink & inkjs)
- **Cây Thoại Rẽ Nhánh Phức Tạp:** Xây dựng trên chuẩn kịch bản Ink chuyên nghiệp với lời thoại mang đậm khẩu khí Sài Gòn cuối thập niên 80.
- **Thước Đo Áp Lực Tâm Lý (Composure Gauge):** Nghi phạm chuyển từ *Vững vàng* $\rightarrow$ *Dao động* $\rightarrow$ *Suy sụp* khi bị đập tan lời khai gian dối.
- **Đối Chất Vật Chứng:** Trình thẻ tang vật trực tiếp vào mặt nghi phạm để mở khóa nhánh thú tội.

### 4. Thiết Kế Mỹ Thuật Diegetic Saigon Noir (Không Web-Slop)
- 100% chi tiết đồ họa đều mô phỏng vật thể vật lý trên bàn làm việc của điều tra viên:
  - Tập hồ sơ bìa giấy Manila, dấu mộc đỏ `TỐI MẬT`, `CÔNG AN TP. HỒ CHÍ MINH`.
  - Ảnh chân dung can phạm Polaroid chụp với bảng phấn cầm tay.
  - Sổ tay bọc da viền chỉ với ruột giấy kẻ ô carô ố vàng ghi chú lời khai.
  - Máy cassette Sony TCM-7 phát lại băng thâu âm lời khai nhân chứng.

- **Runtime & UI:** React 18, Vite 5, Tailwind CSS
- **3D Graphics:** Three.js (r170)
- **2D Graphics & Canvas:** Pixi.js (v8), Phaser (v3.88)
- **Narrative:** Inkle Ink (`inkjs`)
- **State Management:** Zustand
- **Audio Engine:** Howler.js (Gated behind first user gesture complying with Browser Autoplay Policy)
- **Storage:** LocalForage (IndexedDB save slots schema)

## 🚀 Hướng Dẫn Cài Đặt & Khởi Chạy (Getting Started)

### 1. Yêu cầu hệ thống
- **Node.js**: Phiên bản 18.0.0 trở lên
- **npm** hoặc **pnpm** / **yarn**

### 2. Cài đặt các gói phụ thuộc
```bash
git clone https://github.com/hungvdn1314/minh-sat.git
cd minh-sat
npm install
```

### 3. Chạy môi trường phát triển (Development)
```bash
npm run dev
```
Mở trình duyệt truy cập: `http://localhost:5173/`

### 4. Đóng gói bản phát hành (Production Build)
```bash
npm run build
npm run preview
```
Bản dựng tối ưu hóa sẽ được xuất ra thư mục `dist/`.
